RecipeFlow — web app per iPhone (e Android, PC)
================================================

PUBBLICARLA GRATIS SU GITHUB PAGES (una volta sola, ~5 minuti, dal PC)
1. Vai su github.com e accedi (o crea un account gratuito).
2. In alto a destra "+" → "New repository". Nome: recipeflow. Visibilità: Public. "Create repository".
3. Nella pagina del repository clicca "uploading an existing file".
   Trascina dentro TUTTO il contenuto di questa cartella (index.html, sw.js, manifest.webmanifest,
   recipes.json e le cartelle icons e src). Poi "Commit changes".
4. Settings → Pages → "Build and deployment": Source = "Deploy from a branch", Branch = main, cartella / (root) → Save.
5. Dopo 1-2 minuti l'app è online a:  https://TUO-NOME-UTENTE.github.io/recipeflow/
   (l'indirizzo esatto compare in cima alla pagina Settings → Pages).

INSTALLARLA SULL'IPHONE
1. Apri l'indirizzo con SAFARI.
2. Tocca Condividi (il quadrato con la freccia) → "Aggiungi alla schermata Home" → Aggiungi.
3. Apri RecipeFlow dall'icona → Altro → Impostazioni → incolla la chiave gratuita di Gemini
   (aistudio.google.com → Create API key) → "Salva e prova".
Usala sempre dall'icona: su iPhone l'app installata e la scheda di Safari hanno memorie separate.
Su Android: apri l'indirizzo con Chrome → menu ⋮ → "Installa app".

DA SAPERE
- Non scade mai e non serve nessun account Apple. I dati restano sul telefono.
- Per spostarli su un altro telefono: Impostazioni → Esporta backup / Importa backup.
- Timer: su iPhone l'app deve restare aperta (schermo acceso) perché il timer suoni.
- Aggiornamenti: carica i nuovi file nello stesso repository (sostituendo i vecchi);
  l'app si aggiorna da sola alla prossima apertura.
- La chiave di Gemini NON è nei file pubblicati: resta solo nel tuo telefono.
